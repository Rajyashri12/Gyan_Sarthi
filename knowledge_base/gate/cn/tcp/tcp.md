# Computer Networks - TCP

TCP stands for Transmission Control Protocol.

TCP is a connection-oriented transport layer protocol.

TCP provides reliable and ordered delivery of data.

Important TCP concepts include:

- Three-way handshake
- Sequence numbers
- Acknowledgements
- Flow control
- Congestion control
- Retransmission

The TCP three-way handshake uses SYN, SYN-ACK and ACK messages
to establish a connection.
